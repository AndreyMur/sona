# PRD: Sona — голосовой учёт личных финансов

**Дата**: 29.09.2026
**Статус**: Draft
**Версия**: 1.2 (MVP v1.0)

## Обзор продукта

Sona — кроссплатформенное мобильное приложение (iOS 16+, Android 10+) для личного учёта финансов, в котором основным способом ввода операции является голос. Пользователь произносит фразу («такси 400», «потратил 2300 на продукты»), приложение распознаёт речь, разбирает её в структурированные операции (тип, сумма, категория, подкатегория, дата) и сохраняет их.

**Решаемая проблема:** вести учёт расходов вручную долго и скучно, поэтому люди бросают это занятие. Существующие приложения требуют ручного выбора категорий и заполнения форм.

**Целевая аудитория:** люди 20–45 лет, которые хотят контролировать личные расходы, но не готовы вести таблицы; пользователи в России, кому важен быстрый ввод «на ходу» и работа без облака.

**Ключевая ценность:** «Скажи — я запишу». От фразы до сохранённой операции — до 3 секунд.

## Цель

Дать пользователю возможность записывать финансовые операции голосом или текстом за секунды, автоматически раскладывая их по категориям, и контролировать лимиты без таблиц.

## Цели и бизнес-задачи

- Снизить порог входа в учёт финансов: время на одну операцию ≤ 3 секунд.
- Обеспечить монетизацию через подписку Sona Pro (349 ₽/мес или 2 490 ₽/год).
- Держать себестоимость AI-обработки в пределах $0.5–1.0 на активного пользователя в месяц.
- Обеспечить работу приложения без облака (ручной ввод + локальный парсер).

## Пользовательские сценарии

- Пользователь нажимает «Сказать» и произносит «такси 400» -> операция сохраняется с категорией «Транспорт / Такси» и суммой 400 ₽.
- Пользователь произносит «потратил 2300 на продукты и 600 на такси» -> создаются две отдельные операции, обе показаны карточками для подтверждения.
- Пользователь вводит текст «кофе 450» -> AI разбирает фразу так же, как голосовую, и создаёт операцию.
- Пользователь без интернета записывает трату -> срабатывает локальный парсер, показывается бейдж «Офлайн-разбор».
- Пользователь хочет узнать остаток -> произносит «Баланс» -> показывается текущий баланс.
- Пользователь хочет узнать лимит по категории -> произносит «Сколько на продукты» -> показывается остаток по категории.
- Пользователь передумывает во время ввода -> произносит «Отмена» -> операция не сохраняется.
- Пользователь приближается к лимиту -> получает push на 50 / 80 / 100% -> видит прогресс бюджета.
- Пользователь хочет исправить категорию -> открывает карточку операции и меняет категорию вручную.
- Пользователь включает «Только ручной ввод» -> приложение работает полностью локально, без отправки аудио в облако.

## В скоупе (MVP v1.0)

- Распознавание речи (STT) и разбор текста в структуру (NLU) через OdiRouter.ai.
- Локальный fallback-парсер (регулярки + словарь категорий 300–500 слов) с бейджем «Офлайн-разбор» и кнопкой «Уточнить через AI».
- Ручная корректировка и обучение категоризации.
- Аналитика: табы Неделя / Месяц / Год / Период, сумма трат, % к прошлому периоду, бар-чарт, топ категорий, фильтры.
- Бюджет: месячный бюджет, пончик-диаграмма, лимиты по категориям/подкатегориям, пороги 50/80/100%, прогноз до конца месяца, перенос остатка (опция).
- Профиль: аватар, имя, email, скоринг «Финансовое здоровье» (0–100), меню (данные, счета, категории, уведомления, безопасность, подписка, выход).
- Категории и подкатегории по умолчанию (16 категорий).
- Push-уведомления о лимитах (50/80/100%, превышение, ежедневное напоминание, еженедельный отчёт, регулярные платежи, достижение цели, аномалии трат).
- Локальное хранение данных с шифрованием.
- Freemium + подписка Sona Pro с пробным периодом 7 дней.
- Тёмная тема (Системная / Светлая / Тёмная).
- Локализация интерфейса: RU.

## Функциональные требования

### Запись и разбор
- Аудио записывается в `.m4a` (16 kHz, mono).
- Основная STT-модель: `openai/gpt-4o-mini-transcribe`; опция «Максимум» (`openai/gpt-4o-transcribe`) для Pro; fallback `openai/whisper-large-v3`.
- Основная NLU-модель: `google/gemini-3.8-flash`; fallback `openai/gpt-4o` при confidence < 0.7.
- Ответ NLU — JSON-схема операций (тип, сумма, категория, подкатегория, дата).
- Одна фраза может порождать несколько операций.
- Системный промпт версионируется, хранится в конфиге и обновляется через remote config без релиза.
- Пользователь может подтвердить, изменить или отменить распознанные операции.

### Настройки качества
- «Качество распознавания: Стандарт / Максимум (Pro)».

### Бюджет и лимиты
- Общий бюджет месяца, лимиты по категориям и подкатегориям.
- Настраиваемые пороги 50/80/100%, прогноз до конца месяца, опция переноса остатка.

### Монетизация
- Бесплатно: 30 операций/мес, ручной ввод, базовая статистика, 1 бюджет.
- Sona Pro: неограниченный голосовой ввод, полная аналитика, неограниченные бюджеты и цели, прогнозы и советы, экспорт, приоритетная обработка.

## Нефункциональные требования

- Запуск приложения ≤ 1.5 сек.
- От голосового ввода до сохранения операции ≤ 3 сек.
- Офлайн-режим: ручной ввод + локальный парсер.
- Размер приложения ≤ 60 МБ.
- Тёмная тема.
- Доступность: Dynamic Type, VoiceOver / TalkBack.
- Данные хранятся локально с шифрованием (SQLCipher).
- Аудио отправляется в облако только на время обработки.
- Защита входа: PIN / Face ID / Touch ID, автоблокировка.
- Экспорт и удаление данных одной кнопкой.
- Трафик шифруется; опция «Только ручной ввод» без облака.

## Дизайн и UX

- Стиль: чистый, спокойный, «финансовый wellness».
- Цвета: Primary `#0F6B4F`, Accent `#D4F0E2`, фон-градиент `#E8F5EE → #FFFFFF`, текст `#1A1A1A` / `#6B7280`, доход `#16A34A`, расход `#1A1A1A`, ошибка `#DC2626`, предупреждение `#F59E0B`.
- Типографика: Inter / Manrope; заголовки 28–32pt bold, тело 15–16pt.
- Ключевой экран — запись: волновая анимация (Rive) в состоянии «Слушаю».
- Быстрый запуск: тап по иконке → микрофон уже пульсирует (deep link).

## Технические ограничения

- Платформы: iOS 16+, Android 10+; Flutter 3.22+ (Dart 3.4+).
- Единственный AI-провайдер — OdiRouter.ai (точка отказа); митигация — локальный парсер и возможность переключения на прямые API OpenAI/Google.
- Нет streaming в MVP: задержка «записал → отправил» 800–1500 мс на короткую фразу.
- Точность локального парсера ~70% против ~95% у AI.
- Секреты хранятся в flutter_secure_storage; требуется backend-прокси к OdiRouter.

## Ограничения и риски

- Зависимость от доступности и тарифов OdiRouter.ai.
- Качество распознавания русскоязычной речи и категоризации при низкой confidence.
- Стоимость AI при росте числа операций на пользователя.
- Прохождение модерации in-app purchase для подписки.
- Срок MVP ~10–12 недель для команды: 1 Flutter-разработчик, 1 дизайнер, 1 backend.
- Предположение: короткие фразы (3–7 сек) достаточны для типичного сценария учёта.

## Критерии успеха (KPI)

- Доля операций, созданных голосом, ≥ 60% от всех операций активного пользователя.
- Точность категоризации через AI ≥ 90% на тестовом наборе из 50 фраз.
- WER для STT на русскоязычном тестовом наборе в пределах приемлемого для коротких фраз.
- Медианное время «голос → сохранено» ≤ 3 сек.
- Конверсия из бесплатного тарифа в Sona Pro ≥ 3% в течение 30 дней.
- Retention D30 ≥ 20%.
