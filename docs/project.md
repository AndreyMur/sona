\# Техническое задание на мобильное приложение Sona (v1.2)



С учётом подтверждённого названия \*\*Sona\*\* и выбранного AI-провайдера \*\*OdiRouter.ai\*\* вношу правки в ТЗ. Ниже — обновлённые разделы и полная сводка.





\## 1. Общая информация



\*\*Название:\*\* Sona  

\*\*Tagline:\*\* «Скажи — я запишу»  

\*\*Тип:\*\* кроссплатформенное мобильное приложение для личного учёта финансов  

\*\*Платформы:\*\* iOS 16+, Android 10+  

\*\*Фреймворк:\*\* Flutter 3.22+ (Dart 3.4+)  

\*\*Язык интерфейса:\*\* русский  

\*\*Валюта:\*\* выбирается в настройках, по умолчанию ₽  

\*\*Хранение данных:\*\* локально (SQLite + шифрование)  

\*\*Монетизация:\*\* подписка (оплата AI-обработки)  

\*\*AI-провайдер:\*\* OdiRouter.ai



\*\*Почему Sona:\*\* короткое, мягкое, международное. Ассоциации: sound, sonar, «соната». Легко произносится на русском и английском, хорошо смотрится в логотипе, не занято в финтехе.





\## 2. AI-провайдер: OdiRouter.ai



\*\*Что это:\*\* облачный агрегатор, дающий доступ к 200+ ведущим AI-моделям через единый API-ключ. Включает OpenAI, Claude, Gemini, Grok, Kimi, а также модели для изображений, видео, аудио и 3D.



\*\*Ключевые преимущества для Sona:\*\*

\- \*\*Единый API\*\* — не нужно отдельно настраивать OpenAI, Google и других провайдеров.

\- \*\*Умная маршрутизация\*\* — запросы автоматически направляются по цене, задержке и доступности, приложение остаётся стабильным при сбоях провайдеров.

\- \*\*Доступ из России\*\* — маршрутизация рассчитана на стабильный доступ без дополнительной настройки сети.

\- \*\*Прозрачные цены\*\* — видны до отправки запросов, можно выбрать более дешёвый вариант.

\- \*\*Контроль затрат\*\* — управление API-ключами, логи запросов, шифрование трафика.



\*\*Модели для Sona (распознавание речи + разбор):\*\*



OdiRouter предоставляет доступ к STT-моделям через endpoint `/v1/audio/transcriptions`. Рекомендуемые модели:



| Задача | Модель | Цена | Особенность |

|---|---|---|---|

| \*\*STT (основная)\*\* | `openai/gpt-4o-transcribe` | \~$0.006/мин | Высокая точность, понимает контекст |

| \*\*STT (эконом)\*\* | `openai/gpt-4o-mini-transcribe` | \~$0.003/мин | Дешевле, хорошее качество |

| \*\*STT (классика)\*\* | `openai/whisper-large-v3` | По длительности | Надёжный, проверенный |

| \*\*NLU (разбор текста)\*\* | `google/gemini-3.8-flash` | \~$0.75/1M вход | Быстрый, дешёвый,结构化 output |

| \*\*NLU (сложные фразы)\*\* | `openai/gpt-4o` | \~$0.005/1K | Точный разбор, понимает контекст |



\*\*Логика работы:\*\*

1\. Аудио записывается в `.m4a` (16 kHz, mono).

2\. Отправляется на `/v1/audio/transcriptions` через OdiRouter с моделью `gpt-4o-mini-transcribe` (эконом) или `gpt-4o-transcribe` (точность).

3\. Полученный транскрипт отправляется в LLM (`gemini-3.8-flash`) с промптом для извлечения структуры операций.

4\. Ответ — JSON со списком операций (тип, сумма, категория, подкатегория, дата).



\*\*Fallback:\*\* если OdiRouter недоступен — локальный парсер по правилам (регулярки + словарь категорий). Пользователь видит бейдж «Офлайн-разбор».

\# Ответы на открытые вопросы



Отвечаю сам, с обоснованием. Это финальные решения для ТЗ Sona v1.2.



\---



\## 1. Модель STT по умолчанию



\*\*Решение:\*\* `openai/gpt-4o-mini-transcribe` как основная, `openai/gpt-4o-transcribe` как опция для Pro.



\*\*Почему:\*\*

\- Разница в цене вдвое ($0.003 vs $0.006 за минуту), а качество для коротких фраз типа «такси 400» практически одинаковое.

\- Средняя длина фразы в Sona — 3–7 секунд, то есть стоимость одной операции ≈ $0.0003–0.0007. Даже на бесплатном тарифе это копейки.

\- `gpt-4o-transcribe` включаем только для Pro-пользователей или когда пользователь нажал «Улучшить точность» — если модель не уверена в распознавании.

\- Fallback-модель на случай недоступности: `openai/whisper-large-v3`.



\*\*В настройках:\*\* «Качество распознавания: Стандарт / Максимум (Pro)».



\---



\## 2. Модель NLU (разбор текста в структуру)



\*\*Решение:\*\* `google/gemini-3.8-flash` как основная, `openai/gpt-4o` как fallback для сложных случаев.



\*\*Почему:\*\*

\- Gemini Flash — самая дешёвая из качественных моделей ($0.75 за 1M входных токенов), а задача у нас простая: текст → JSON.

\- Для типичной фразы («потратил 2300 на продукты и 600 на такси») уходит \~200 токенов. Стоимость разбора ≈ $0.0002.

\- Если Gemini не смог разобрать (низкая confidence < 0.7) — автоматически отправляем в `gpt-4o` через OdiRouter. Умная маршрутизация как раз для этого.

\- Structured output: используем `response\_format: json\_schema` с жёсткой схемой операций.



\*\*Промпт:\*\* один системный промпт, версионируется. Хранится в конфиге приложения, обновляется через remote config без релиза.



\---



\## 3. Streaming



\*\*Решение:\*\* в MVP — \*\*нет\*\*. «Записал → отправил» целиком.



\*\*Почему:\*\*

\- Streaming добавляет сложности: WebSocket, буферизация чанков, склейка транскрипта, обработка обрывов. Для MVP это лишнее.

\- Реальная задержка без стриминга: 800–1500 мс для короткой фразы. Это приемлемо.

\- Пользователь всё равно видит анимацию «слушаю» и «разбираю» — субъективно быстро.

\- Streaming вводим в \*\*v1.1\*\* для Pro, если метрики покажут, что пользователи жалуются на скорость.



\---



\## 4. Локальный fallback-парсер



\*\*Решение:\*\* \*\*в MVP\*\*. Обязательно.



\*\*Почему:\*\*

\- Без него приложение не работает в метро, самолёте, за границей без роуминга. Это критично для финансового приложения — записать трату нужно здесь и сейчас.

\- Реализация: регулярки + словарь категорий (300–500 ключевых слов: «такси», «пятёрочка», «кофе», «аптека»).

\- Точность ниже (\~70% против 95% у AI), но лучше, чем ничего.

\- UI: бейдж «Офлайн-разбор», после появления сети — кнопка «Уточнить через AI».



\---



\## 5. Тёмная тема



\*\*Решение:\*\* \*\*в MVP\*\*.



\*\*Почему:\*\*

\- Flutter даёт это почти бесплатно, если сразу заложить `ThemeData` с двумя режимами.

\- Финансовые приложения часто смотрят вечером в постели — тёмная тема ожидаема.

\- Откладывание на потом = переделка всех экранов. Дешевле сделать сразу.

\- Режимы: Системная / Светлая / Тёмная.



\---



\## 6. Виджеты



\*\*Решение:\*\* \*\*в v1.1\*\*, не в MVP.



\*\*Почему:\*\*

\- Виджеты требуют отдельного кода на Swift (WidgetKit) и Kotlin (Glance). Это +2–3 недели разработки.

\- Сначала нужно проверить, что основной сценарий (кнопка → голос → запись) работает и нравится.

\- В MVP достаточно быстрого запуска приложения: тап по иконке → микрофон уже пульсирует (deep link).

\- В v1.1: виджет «Баланс + кнопка Сказать» на домашний экран и экран блокировки.



\---



\## 7. Тестовый endpoint OdiRouter



\*\*Решение:\*\* \*\*да, обязательно\*\*, до начала разработки.



\*\*Почему:\*\*

\- Нужно проверить реальные цены, задержки и качество на русскоязычных фразах.

\- OdiRouter даёт доступ ко всем моделям через один ключ — можно прогнать один и тот же набор из 50 тестовых фраз через Gemini, GPT-4o, Claude и выбрать лучшую по соотношению цена/качество.

\- Тестовый набор:

&#x20; - «Такси 400»

&#x20; - «Потратил 2300 на продукты в Пятёрочке»

&#x20; - «Зарплата 80 тысяч пришла»

&#x20; - «Кофе и круассан 450»

&#x20; - «Вчера потратил 1500 на бензин и 300 на мойку»

&#x20; - «Получил возврат 1200 от озона»

&#x20; - и ещё 44 фразы разных типов.



\*\*Метрики:\*\* WER (word error rate) для STT, точность категоризации для NLU, средняя задержка, средняя стоимость запроса.



\*\*Бюджет на тесты:\*\* $20–30 хватит с головой.
